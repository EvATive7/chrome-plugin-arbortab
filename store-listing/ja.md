ArborTab — Chrome ネイティブ縦型タブをツリー化

Windows x64 専用です。Chrome のネイティブ縦型タブが必要です。完全な表示統合には、GitHub から別途オープンソースのネイティブモジュールをインストールする必要があります。インストール前に下記のセキュリティ説明をお読みください。

ArborTab は、サイドバーや二重のタブ一覧を使わず、Chrome 本来の縦型タブ内で親子関係を持つツリーを管理します。

機能：

- リンクから開いたタブを、開いた元のタブの子にします。
- サブツリー全体を折りたたみ／展開できます。
- 親タブとすべての子孫をまとめて閉じられます。
- タブを別のタブへドロップして子にするか、端へドロップして兄弟順を変更できます。
- インデントガイド、非表示タブ数、テーマ連動色、任意のアニメーション。
- 折りたたみ、ツリーを閉じる、インデント／アウトデントのショートカット。

拡張機能だけでもツリーの維持、タブ順の変更、ショートカット、サブツリー単位の終了は動作します。ネイティブモジュールがない場合、Chrome のタブ表示は平坦なままです。

ネイティブモジュール：

拡張機能のインストール後に ArborTab の設定を開くと、最新 GitHub Release とインストールコマンドが表示されます。ソース、スクリプト、パッケージ、チェックサム、アンインストール手順：
https://github.com/EvATive7/chrome-plugin-arbortab

インストールコマンド：
powershell -NoExit -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/EvATive7/chrome-plugin-arbortab/releases/latest/download/install.ps1 | iex"

セキュリティ説明：

ネイティブ部品は `chrome.exe` と同じ場所に置く `version.dll` プロキシで、縦型タブのレイアウト、描画、マウス、ドラッグ処理に統合します。配布 DLL は Microsoft 署名ではないため、Chrome の子プロセスで「Microsoft 署名済みバイナリのみ」を許可する緩和策を無効にします。その結果、コード整合性の保護が低下します。このトレードオフを確認し同意した場合のみインストールしてください。アンインストーラーが付属します。

プライバシー：

広告、解析、プロジェクト運営サーバーはなく、閲覧データをアップロードしません。拡張機能とモジュールは Native Messaging でローカル通信します。モジュールは GitHub/jsDelivr から署名済み互換データを取得しますが、URL、タイトル、ツリーは送信しません。診断情報は、ユーザーが明示的に書き出して共有しない限り端末内に留まります。
